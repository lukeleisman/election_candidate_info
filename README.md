# Chicago election candidate info

This repository collects public information about candidates running for office in Chicago:
endorsements, campaign funding (amounts and number of donors), field activity such as door
knocking, stated platforms, and links to filed forms.

## Status: planning

Nothing is built yet. The first target is the **February 23, 2027 aldermanic election**
(petition filing Oct 19–26, 2026). Later phases may extend to mayoral and other races.

## Planned

- Ingest a table of declared aldermanic candidates.
- Campaign finance from the Illinois State Board of Elections bulk data files and from
  Illinois Sunshine (Reform for Illinois), shown side by side.
- A candidate → campaign committee crosswalk, confirmed by hand rather than guessed.
- Later: endorsements, door-knocking claims and proxies, candidate platforms and questionnaires.

Every source used will be documented with its URL and retrieval time.
